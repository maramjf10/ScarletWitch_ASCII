# ScarletWitch_ASCII

A typographic project that renders an image using python. arranges letters in a spiral way to give the result of the image.

this piece shows a picture of Marvel Studios' Scarlet Witch rendered by using the phrase "this is chaos magic wanda" in a spiral.
